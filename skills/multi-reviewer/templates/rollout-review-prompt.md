## 评估方法(纪律)

1. **基础设施事实核查 > LLM 印象**:任何对 CI/CD / 监控 / 灰度能力 / 回滚链路的引用,都要打开配置文件核对
2. **历史故障 > 行业通用清单**:关心方案是否考虑了**本项目 / 本团队历史踩过的发布事故**
3. **回滚预案的可执行性**:回滚条件、回滚到哪一版、回滚多久内完成,要具体到操作步骤
4. **告警阈值的合理性**:阈值是基于历史 P50/P99 还是凭感觉?上线变更后阈值是否需要联调
5. **数据迁移的幂等性**:DDL 顺序、跟代码合入时序、可重入(rerun)
6. **runbook 完整性**:操作步骤要可被一个不熟悉的值班同事跟着跑通
7. **避免无据猜测**:不能验证的项目应明确标 "🟡 未核实" 而非断言
